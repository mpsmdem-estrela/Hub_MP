Identidade Visual para Power BI e Apresentações Executivas

Versão Técnica da Identidade Visual para Power BI e Apresentações Executivas – MP Serviços

Estrutura padronizada para uso em dashboards gerenciais e apresentações institucionais, baseada em boas práticas de design analítico e recomendações da Microsoft para consistência visual em relatórios corporativos.

1Objetivo da Padronização

Garantir:

  • Consistência visual entre dashboards, relatórios e apresentações
  • Melhor leitura analítica (data visualization)
  • Padronização para indicadores financeiros e operacionais
  • Governança visual em materiais gerenciais

Aplicável a:

Power BIExcel dashboardsPowerPoint executivoRelatórios de controladoria

1.1Logo

Aplicações da marca usadas neste manual: assinatura principal e versão de baixa opacidade para fundos, sempre preservando contraste e legibilidade.

Assinatura principalUso sobre fundo claro, com área de respiro.
Aplicação de fundoBaixa opacidade; não competir com os dados.

6Template JSON para Tema Power BI

Pronto para uso:

{
  "name": "MP Servicos Theme",
  "dataColors": [
    "#0F2233",
    "#2E5A88",
    "#4F7FB3",
    "#9AA3A8",
    "#C7CED4"
  ],
  "background": "#FFFFFF",
  "foreground": "#0F2233",
  "tableAccent": "#2E5A88"
}

Aplicação: Menu → Exibir → Tema → Importar tema

7Padrão para Apresentações Executivas (continuação)

Slide de indicadores

Estrutura recomendada:

  • 3 a 5 KPIs por linha
  • Uso de ícones minimalistas
  • Gráficos simples (sem efeitos 3D)

Slide de evolução

Usar:

  • Gráfico de linha
  • Azul técnico
  • Fundo branco
